# TopBrain Studio

Personal, non-commercial anatomy education project. The maintainer's canonical strategy is local-only at `~/.claude/strategies/topbrain-studio.md`; it is not required to run this repository.

This GitHub repository distributes code and one maintainer-approved public reference atlas derived from the official BodyParts3D 4.0 PART-OF archive. The approved atlas contains 24 selected structures: cerebral vessels, skull, brain, and proximal supply segments (ascending aorta, aortic arch, brachiocephalic trunk, bilateral common carotid and subclavian arteries). It does not include the complete aorta. Four dashed `connectionGuides` bridge gaps where the archive lacks cervical carotid or vertebral segments; they are explicitly schematic display guides, not official meshes or validated vessel paths. The only public data files allowed are `public/reference/bodyparts3d.glb`, `public/reference/bodyparts3d.json`, and `public/reference/ATTRIBUTION.txt`; all three are required for publication. Keep the official source archive, CC BY 4.0 license link, required Database Center for Life Science credit, and conversion changes documented with this atlas. It is an adult male reference atlas, not a mask from the same subject as any imported case; never present it as spatially registered to TopBrain or TotalSegmentator data.

Never commit, upload, attach to releases or distribute TopBrain source volumes, segmentations, derived GLB geometry, JSON manifests or case-specific spatial metadata. Keep these files in ignored local storage, including `private-assets/`; do not put them in `public/` or documentation. Any other public anatomy asset needs a new explicit maintainer decision. Tests must generate synthetic fixtures.

TopBrain supplies vascular segmentations; do not label illustrative head shells or invented anatomy as TopBrain data. Keep source provenance, coordinate transforms, label IDs and the original dataset license attached to locally imported assets. This application is not a diagnostic device. Do not copy company CAD or proprietary code into this repository. Do not choose or change a code license without the maintainer's instruction. No git add/commit/push without an explicit user request.

Verify changes with `npm test`, `npm run build`, then a real browser interaction and visual check for scene changes. Tests alone do not prove WebGL rendering.
